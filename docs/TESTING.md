# الاختبار

> لا تختبر على الموقع الحي ولا ببيانات المستخدم الحقيقية. كل الاختبارات في سياق متصفح جديد فارغ ببيانات تجريبية.

## فحص سريع
```bash
node --check script.js
```

## الاختبار الآلي (`tests/smoke.mjs`)
يشغّل خادماً محلياً للمستودع، ويفتح الموقع في Chromium (Playwright) بسياق فارغ، ويزرع سجلات تجريبية، ثم يتحقق من:
- تحميل الصفحة دون أخطاء JavaScript.
- سعر كل وكالة حسب «تاريخ السجل» أو فترتها المختارة، وحصتا الإسعاف والتعاون من سعر كل وكالة.
- أداة «تسعير السجلات المحفوظة حسب تاريخها»: الاستثناء، التنفيذ، والتراجع المطابق للأصل حرفياً.

التشغيل:
```bash
npm install --no-save playwright   # مرة واحدة (أو استخدم Playwright مثبتاً عالمياً)
npx playwright install chromium    # إن لم يكن المتصفح مثبتاً
node tests/smoke.mjs
```
النتيجة: سطر `PASS`/`FAIL` لكل فحص، ورمز خروج غير صفري عند أي فشل.

## فحوص أخطاء المراجعة الشاملة (`tests/review.mjs`)
20 فحصاً للأخطاء التي وجدتها مراجعة 21/10/2026 (Enter لا يحفظ، تعديل الوكالة في مكانها، المسودات، Ctrl+Z بعد الإدراج، الوكالات القديمة، نافذتان، النسخ حين تتعذر القراءة، الاستعادة مع Firebase…):
```bash
node tests/review.mjs
```

## ميزات 3/11/2026 (`tests/features.mjs`)
إيصال حد أدنى أتعاب (150، على المندوب لا على الوكالة)، ملاحظة السجل (حفظ، تقرير، فتح، سجل جديد)، Ctrl+D، تنبيه الرقم الناقص، إشعار بلون النوع، رقم الوكالة أرقام فقط، ألوان التدقيق السريع، وسجل قديم بلا الحقول الجديدة:
```bash
node tests/features.mjs
```

## الأداء ببيانات كبيرة (`tests/perf.mjs`)
40 سجلاً × 100 وكالة (~5 ملايين حرف، قريب من بيانات المستخدم الحقيقية): يقيس فتح صفحة التقارير (يجب أن تعرض 200 صف فقط) والمزامنة الدورية مع خادم Firebase وهمي (يجب أن تكون شبه مجانية بلا تغيير):
```bash
node tests/perf.mjs
```

## اختبار يدوي قبل الدفع إلى `main`
1. افتح `index.html` محلياً (أو عبر `python3 -m http.server`) في نافذة خاصة.
2. أنشئ سجلاً تجريبياً بوكالات من أنواع وفترات مختلفة، واحفظه، وافتح تقريره وحصص اللجان.
3. جرّب النسخة الاحتياطية والاستعادة.
4. على الموقع الحي: اطلب من المستخدم **تنزيل نسخة احتياطية أولاً**، ثم ادمج.
