# الاختبار

> لا تختبر على الموقع الحي ولا ببيانات المستخدم الحقيقية. كل الاختبارات في سياق متصفح جديد فارغ ببيانات تجريبية.

## فحص سريع
```bash
node --check script.js
```

## الاختبار الآلي (`tests/smoke.mjs`)
يشغّل خادماً محلياً للمستودع، ويفتح الموقع في Chromium (Playwright) بسياق فارغ، ويزرع سجلات تجريبية، ثم يتحقق من:
- تحميل الصفحة دون أخطاء JavaScript.
- سعر كل وكالة حسب «تاريخ السجل» أو فترتها المختارة، وحصتا الإسعاف والتعاون من سعر كل وكالة.
- أداة «تسعير السجلات المحفوظة حسب تاريخها»: الاستثناء، التنفيذ، والتراجع المطابق للأصل حرفياً.

التشغيل:
```bash
npm install --no-save playwright   # مرة واحدة (أو استخدم Playwright مثبتاً عالمياً)
npx playwright install chromium    # إن لم يكن المتصفح مثبتاً
node tests/smoke.mjs
```
النتيجة: سطر `PASS`/`FAIL` لكل فحص، ورمز خروج غير صفري عند أي فشل.

## تخصيص التقرير (`tests/report.mjs`)

```bash
node tests/report.mjs
```

## الفرز والمقاصة والتقارير المخصّصة (`tests/builder.mjs`)
فرز السجلات وفلترتها باسم المندوب، المقاصة (السبب إلزامي، الصافي، لا تغيير في الإجمالي والحصص والوكالات، لوحة التحكم والجدول، تأكيد الحسم الأكبر من المطلوب)، والتقرير المخصّص (المحدد فقط، قالب 4 أعمدة، إضافة عمود وتقديمه، لا مدققين، التجميع والمجاميع، سطر لكل وكالة، حفظ القالب وحذفه، CSV، Excel، مستند الطباعة):
```bash
node tests/builder.mjs
```

## السجلات المستردة (`tests/recovered.mjs`)
النموذج السريع والتحقق، الشارة والفلتر، عدم دخولها في أرقام التدقيق، فتحها وتعديلها، استيراد CSV بحالات المعاينة، المكرر عند اختياره، المطابقة (الأعداد والمكرر والناقص)، التقرير المخصّص، وصلاحية النسخة الاحتياطية:
```bash
node tests/recovered.mjs
```

## إعادة الترقيم وهوية السجل (`tests/renumber.mjs`)
حذف وكالة مع «إعادة ترقيم ما بعدها»، ونافذة «إعادة الترقيم» (تعبئة السلسلة) والتراجع، ورقم السجل غير الفريد (التكرار = الرقم + المندوب + المكتب) في الحفظ والاستيراد والمطابقة، و«شرح النظام» داخل الإدارة:
```bash
node tests/renumber.mjs
```

## اختبار يدوي قبل الدفع إلى `main`
1. افتح `index.html` محلياً (أو عبر `python3 -m http.server`) في نافذة خاصة.
2. أنشئ سجلاً تجريبياً بوكالات من أنواع وفترات مختلفة، واحفظه، وافتح تقريره وحصص اللجان.
3. جرّب النسخة الاحتياطية والاستعادة.
4. على الموقع الحي: اطلب من المستخدم **تنزيل نسخة احتياطية أولاً**، ثم ادمج.
