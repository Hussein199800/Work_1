# نظام تدقيق السجلات والوكالات

نظام عربي لتدقيق سجلات الوكالات القضائية ومبالغها (فرع إدلب لنقابة المحامين): إدخال السجلات والوكالات، حساب الأسعار والإضافات والطوابع وبدل الانتقال وحصص لجنتي الإسعاف والتعاون، والتقارير والطباعة وExcel، والنسخ الاحتياطي.

- **الموقع:** https://hussein199800.github.io/Work_1/
- **الفكرة والنسخة الأولى المنشورة:** شذى البكور وباسل البكور — https://shaza-albakkour.github.io/agencies/
- **التطوير منذ 30 أيلول 2026 (مستودع Work_1):** حسين الطويل، بمساعدة Claude (Anthropic).

## التشغيل
صفحة واحدة بلا بناء ولا خادم: افتح `index.html` في المتصفح (أو `python3 -m http.server` ثم افتح العنوان المحلي).
البيانات تُحفظ في متصفح المستخدم (localStorage وIndexedDB)، مع مزامنة اختيارية مع Firebase لاستخدام الموقع من أي جهاز — ونزّل نسخة احتياطية بانتظام من «النسخ الاحتياطي».
